# MealBridge 

A full-stack food redistribution platform that connects food donors, NGOs, and volunteers to reduce food waste and support communities.

## Features

### Donor

* Create food donations
* Track donation status
* View impact statistics
* Real-time dashboard updates

### NGO

* Browse available donations
* Claim food donations
* Monitor claims
* Impact tracking dashboard

### Volunteer

* View available deliveries
* Accept delivery requests
* Mark deliveries as completed
* Real-time updates

### Authentication

* JWT Authentication
* Google OAuth Login
* Role-Based Access Control

## Tech Stack

### Frontend

* React
* React Router
* Axios
* Bootstrap
* CSS

### Backend

* FastAPI
* SQLAlchemy
* Pydantic
* JWT Authentication

### Database

* SQLite
